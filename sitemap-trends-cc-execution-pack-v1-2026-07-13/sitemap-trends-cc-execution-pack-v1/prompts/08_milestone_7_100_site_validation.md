# Milestone 7：100 站稳定化

## 目标

在不引入分布式复杂架构的情况下，让约 100 个站稳定运行。

## GitHub Actions

- 5 个 shard
- 每 shard 约 20 站
- shard 内并发 4～5
- 单请求超时 15～20 秒
- 最多重试 2 次
- 429 指数退避
- 单站失败隔离
- 手动运行单 shard
- 输出统计摘要

## 验证顺序

1. fixture
2. 3 站
3. 10 站
4. 20 站
5. 100 站
6. 连续两个完整周期

## 最终报告

必须包含：

- 总站点
- 成功
- 部分成功
- 失败
- Endpoint
- URL 总量
- 新增 URL
- 疑似游戏
- 审核数
- 总耗时
- 最慢站点
- 高频错误
- 数据污染检查
- 回滚演练
- 已知限制

完成后提交最终验收报告，不自动扩展至 1000 站。
