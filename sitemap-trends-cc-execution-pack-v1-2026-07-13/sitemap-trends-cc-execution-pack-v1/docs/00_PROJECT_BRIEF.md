# 00｜项目总目标

## 1. 产品定位

基于 `Yangjia23/sitemap-diff` 改造一个独立的小游戏 Sitemap 趋势监控系统。

目标规模约 100 个在线小游戏网站。系统按照固定周期运行，发现各站新增的游戏页面 URL，并统计同一游戏在不同独立域名上的新增收录速度。

## 2. 总目标

系统需要完成以下闭环：

```text
站点注册
→ robots.txt / 手工配置发现 Sitemap
→ 递归解析 Sitemap Index
→ 解析 XML / XML.GZ
→ 第一次建立基线
→ 后续发现新增 URL
→ 识别疑似游戏页面
→ 提取候选游戏名
→ 聚合同一游戏的多站来源
→ 输出每日新增地址清单
→ 计算 24h / 7d / 30d 新增域名数
→ Dashboard 查看、筛选和导出
```

## 3. 第一版最重要交付

1. 支持约 100 个站点。
2. 单站失败不影响其他站。
3. 首次运行不产生假新增。
4. 抓取失败不覆盖最近一次成功数据。
5. 后续运行准确输出新增 URL。
6. 提供每日新增地址页面。
7. 支持 CSV、JSON、复制全部 URL。
8. 提供站点健康状态。
9. 支持同一游戏跨域名聚合。
10. 提供 24h、7d、30d 原始趋势指标。

## 4. 第一版不追求

- 自动建站
- 关键词搜索量
- SERP 竞争度
- Google Trends 自动分析
- 付费订阅
- 多租户
- 1000 站分布式架构
- 自动绕过所有验证码或强反爬
