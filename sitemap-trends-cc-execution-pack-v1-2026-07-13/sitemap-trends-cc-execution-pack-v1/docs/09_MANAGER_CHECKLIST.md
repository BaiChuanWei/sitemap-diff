# 09｜经理执行清单

## 开始前

- [ ] Fork 上游仓库
- [ ] CC 已连接实际开发仓库
- [ ] 创建开发分支
- [ ] 复制本执行包进仓库
- [ ] 准备约 100 站 CSV
- [ ] 准备测试 fixtures
- [ ] 创建测试 Supabase
- [ ] 配置 GitHub Secrets
- [ ] 确认不连接生产数据库
- [ ] 保存上游许可证与署名

## 每个 Milestone 开始前

- [ ] 上一阶段测试通过
- [ ] 上一阶段已 commit
- [ ] 当前目标只有一个
- [ ] 允许修改范围明确
- [ ] 禁止修改范围明确
- [ ] 输入文件齐全
- [ ] 数据库已备份
- [ ] 回滚点明确

## 每个 Milestone 完成后

- [ ] 查看 git diff
- [ ] 检查越界修改
- [ ] 查看真实测试输出
- [ ] 检查新增依赖
- [ ] 检查 Secret 泄露
- [ ] 检查迁移和 rollback
- [ ] 检查 build
- [ ] 检查失败路径
- [ ] 检查未说明的降级
- [ ] 记录 Commit SHA
- [ ] 确认后再进入下一阶段

## 规模验证顺序

```text
fixture
→ 3 站
→ 10 站
→ 20 站
→ 100 站
→ 连续两个完整周期
```
